# Rokid 3DoF Typewriter Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline in this session. The user approved direct implementation of the design; no further design gate is needed. Implementation is on `codex/rokid-3dof-demo`, with the branch pushed for delivery.

**Goal:** Deliver an installable standalone Android demo for the confirmed 480×640 Rokid glasses.

**Architecture:** A native Java Activity and hardware Canvas view render a fixed text plane through a quaternion inverse-view transform. An independent SensorManager thread selects rotation vector sensors and falls back to pinned x-io Fusion C through JNI. A monotonic playback clock keeps comparison modes synchronized.

**Tech Stack:** Android API 31+, Java 11, AGP 9.3.0, Gradle 9.5.0, NDK 28, CMake, Fusion MIT.

## Files and responsibilities

- `app/src/main/java/com/rokid/stabledemo/MainActivity.java`: fullscreen lifecycle and Rokid keys/broadcasts.
- `.../DemoView.java`: start button, text layout, projection and frame scheduling.
- `.../TrackingController.java`: sensor selection, asynchronous sampling, stale/initializing status and snapshots.
- `.../FusionBridge.java` and `app/src/main/cpp/fusion_jni.c`: bounded JNI ownership and unit conversion.
- `.../core/Quaternion.java`, `Projection.java`: Android-independent rotation and projection.
- `.../core/Playback.java`, `PoseState.java`: monotonic timing, loop and freshness checks.
- `third_party/Fusion/`: unmodified pinned upstream sources and MIT notice.
- `app/src/test/`: behavioral math and timing tests; `app/src/androidTest/`: actual Activity integration checks.
- `tools/`: reproducible verification/build commands; `README.md`: install and hardware validation.
