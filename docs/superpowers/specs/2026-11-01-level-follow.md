# v0.3 水平缓慢回中

用户要求画面偏离中心后在保持水平的同时缓慢移到眼镜中心，并询问补偿是否已最快。本次落实该跟随行为，保持最新姿态快速补偿；不额外加入未经真机校准的预测或滤波延迟。

文字平面中心对准安全视口(240,240)，即480×640屏幕的(240,320)。独立慢锚点只跟随视线yaw/pitch，用 `Ry(yaw)*Rx(pitch)` 保持启动参考中的水平；不追随roll。默认指数时间常数1.5秒，yaw/pitch合成角速度限制12°/秒。渲染变换为 `head⁻¹ * anchor`；直接使用本帧最新head，不平滑整个姿态。

长按立即把锚点移到当前视线，横滚仍补偿；关闭维稳维持原有头锁定比较方式，再开启时从当前正前方开始。传感器参考epoch变更时重置慢锚点，短暂掉帧不产生锚点跳跃。时间常数与速度上限有明确ADB参数与元数据记录。

诊断残差相对每帧自己的移动锚点计算，排除主动回中；CSV记录锚点yaw/pitch。图表下移为中心文字留出空间；播放、日志与续航测试流程保持原语义。

验证覆盖快速姿态响应与慢回中分离、单调收敛、组合旋转水平、长时间歪头、手动回中保留roll、30/120fps一致性、±180°航向跨越、掉帧与角速度限制，以及移动锚点不制造虚假残差。构建、Lint、相关界面/日志仪器测试与模拟器截图通过后交付APK。
