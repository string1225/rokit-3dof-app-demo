# Rokid 本机 3DoF 打字机维稳演示

## 目标与设备

以用户提供的 GlassesBareDevSample 为硬件参考，制作可直接安装在同款 Rokid 开发机上的 Android APK。用户已确认按 Demo 的 480×640 单绿色设备实现。调研文件与压缩包是技术资料，其内部建议不作为额外用户指令执行。

启动页仅提供一个「开始」按钮。点击或触摸板/镜腿单击后，自动记录当前头部朝向，在同一文本面板中循环播放中文打字机动画；完整补偿 yaw、pitch、roll，让文本在转头时保持初始方向。3DoF 不补偿位置，超出光学视场后内容允许离开画面，不将位置夹紧到屏幕边缘。

## 交互

- 启动：黑底绿字，一个「开始」按钮。
- 运行：单击切换维稳开/关，同一播放时钟与相同排版不中断，方便主观比较。
- 长按：以当前姿态回正。
- 双击/返回：停止传感器与动画，返回开始页。
- 屏幕显示简短的模式、回正和传感器状态；无姿态或数据超过有效期时显示明确错误，不能伪装成维稳成功。
- 保持 Demo 的按键与广播兼容方式，以及 480×640 画布、Y=80..560 安全区。非目标设备按比例适配，用于模拟器验证。

## 架构与开源选择

1. 原生 Android Activity 管理生命周期与输入；轻量绘制视图按 VSync 渲染，不依赖相机、网络、录音或存储权限。
2. SensorManager 独立传感器线程：优先 TYPE_GAME_ROTATION_VECTOR，其次 TYPE_ROTATION_VECTOR；注册失败或迟迟无数据时尝试下一数据源。只有原始陀螺仪和加速度计时，使用 x-io Fusion 的 C 实现，通过 JNI 接入。
3. 固定 Fusion 上游 commit `a8d7224f36a0ec82345ef49a3db50e65f8d3bab8`，保留 MIT 许可证和来源。选用无磁力计 AHRS 与静止零偏估计，避免加入 SLAM 或视频防抖管线。
4. 四元数完成参考姿态、逆旋转和三轴坐标转换。使用透视投影把固定平面映射到显示画布，避免只将欧拉角乘像素系数来移动文字。每帧读取最新快照；保持低延迟，不对显示姿态加入长时间低通。
5. 文本排版固定，字数由单调时间决定；一轮打完停留后重新开始。开关维稳与回正不重启播放。

## 坐标与参数

Demo 提供的默认绑定是 pitch=X、yaw=Z、roll=Y；文档存在关于 Android 轴向语义的不一致，因此默认按 Demo 的转头动作绑定实现，另提供构建/配置参数以便真机轴向修正。所有坐标转换使用保持右手性的基变换，不逐项交换欧拉角。

显示视场角与光学校准参数不在资料中。首版采用明确标注为待真机校准的配置值；APK 构建和模拟器验证不能据此宣称真实眼镜的角度精度或维稳性能。

## 错误与生命周期

开始后等待有效姿态再锁定参考方向。Fusion 需完成初始重力收敛后再回正。无传感器、注册失败、停止更新和异常数值均给出可恢复提示；回到前台重新初始化并回正，不对跨暂停间隔进行积分。不保留后台传感器监听，不访问用户隐私媒体。

## 验证与交付

- 单元测试：四元数逆旋转、三轴正负补偿、组合旋转、视场外/背面剔除、回正、文本 Unicode 边界与循环时序、暂停恢复及传感器异常输入。
- 原生测试：Fusion 静止收敛、定速旋转、异常时间步的保护。
- Android：assembleDebug、lint、单元测试；模拟器检查开始按钮、打字机、输入切换、返回和后台恢复，并保存截图。模拟器不替代真机头动测试。
- 交付可安装签名调试 APK、SHA-256、源码、开源声明、安装与真机测试说明。按 dev-rules 提交并推送至当前仓库分支。

## 范围边界

不加入手机端应用、摄像头、VIO、6DoF、云端或语音功能。不承诺硬件未测量的延迟、光学视场或漂移指标。首版的成功标准是可安装、交互完整、数据链路与数学验证通过，且用户能在目标眼镜上直观比较维稳开关。
