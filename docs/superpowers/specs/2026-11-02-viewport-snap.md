# v0.3.2 超过50%立即回中

用户要求：浮窗飘出去X或Y超过50%后直接跳回，不再缓慢飘回。既有慢跟随、重力水平、打字进度及首页操作保留。

50%以安全显示区宽/高为分母，计算投影后的浮窗中心相对视口中心的绝对位移。480×480安全区中，任一轴超过240像素触发；恰好边界不触发。使用屏幕X/Y的OR条件，不使用对角线距离或固定欧拉角阈值；投影沿用当前FOV。浮窗在视野后方也视为越界。

`LevelFollow`增加带`Projection`的update入口，在慢锚点更新之前检查旧锚点的投影。触发时在同帧调用既有yaw/pitch回中，两个位置轴一起回中，保留横滚。范围内继续1.5秒时间常数、12°/秒上限。保留不带投影的纯慢跟随入口用于独立数学验证。

`DemoView`使用带视口检查的入口，跳回时短暂显示「超界 · 已水平回中」，不重启打字机、不重置IMU或水平参考。诊断记录沿用每帧实际锚点，自动跳回与慢回中一样属于主动锚点运动；会话元数据记录触发策略。

先在旧实现上注入16°水平转头并检查同帧绘制的左边框仍在中心应有位置，验证失败后实现。数学验证覆盖四个方向、50%边界、判断顺序、对角线OR条件、歪头后的屏幕轴、横滚保持、不同FOV/视口高度、视野后方/长帧间断和二次越界。构建、Lint、相关仪器测试和签名检查后，生成新版APK并复制到已授权手机Download目录。
