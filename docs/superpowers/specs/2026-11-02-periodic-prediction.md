# v0.4 周期俯仰短时预测

用户授权实现规律性上下抖动的额外预测补偿，保留7行内容区、重力水平、50%越界立即回中和现有输入。首版仅预测俯仰旋转，不声称补偿平移或测得运动到光子延迟。

## 算法与时序

新增无Android依赖的`PitchPredictor`，在传感器线程接收重力参考中的原始融合姿态与采集时间。保留约3.5秒历史、约100Hz训练采样，每100ms拟合1–8Hz单频正弦/余弦及偏置、线性趋势。粗搜索后细化频率，要求至少3个周期、高拟合质量和连续稳定频率才启用。静止、非周期、突变、明显其他方向快速旋转、过期样本与时间断流抑制或重置预测。强度缓入、快速衰减，单帧额外俯仰修正限幅0.75°。

传感器线程发布不可变模型快照；渲染线程只求值，不阻塞等待频率拟合。基于最新真实姿态，加上模型从采集时刻到目标时刻的增量，不用拟合姿态替换原始姿态。前推目标为绘制开始+默认15ms，包含样本年龄后的总预测上限20ms；样本年龄超过25ms不预测。该窗口是保守工程参数，不直接采用现有较粗显示延迟估计。通过水平俯仰轴的四元数旋转保留yaw/roll。

慢跟随和越界检查始终使用实测姿态，避免预测触发主动回中；预测只用于该帧快速补偿。参考系切换和生命周期重启会清空模型，手动yaw/pitch回中不改变传感器参考。

## 操作与诊断

首页保持前两项「3DoF测试」「续航测试」，增加第三项「预测补偿：开/关」，默认开，双击/触屏选择第三项切换设置但不启动负载；单击循环三项、双击进入、长按退出。3DoF页现有单击维稳/长按回中/双击返回继续有效。运行状态显示周期识别情况、预测强度与实际总前推时间。

在同一个预计呈现时刻，用后续IMU姿态同时计算无预测的普通补偿残差和当前补偿残差，基准锚点相同，排除主动跟随。图表增加普通残差，RMS显示普通/当前估计；CSV追加预测开关、总时长、模型频率、强度、修正角及普通残差。所有值均明确是软件估计。

## 验证与边界

先验证旧首页无预测开关，再实现。纯数学测试覆盖稳定正弦的未来姿态误差改善、噪声和偏置、非周期与趋势拒绝、周期突停/转头、时间断流/乱序、前推与角度上限、yaw/roll保持。诊断测试验证同一真实未来姿态下普通/预测残差、公平对比以及主动锚点排除。仪器测试覆盖菜单配置、CSV导出、生命周期和7行布局；实际媒体负载不变。

x-io Fusion继续作为六轴姿态融合备用源码；新增周期预测是本项目实现，无新增第三方依赖。拟合与残差改善是软件测试结果，不能当作目标眼镜光学效果或功耗保证。保留原有耗电记录观察新增计算开销。
