# v0.3.3 内容区安全范围与7行回中布局

用户明确：上下参数显示不计入浮窗的安全显示区；当前回中靠近内容区底部，要求文字增加到7行并回到内容区中央。

按现有上方状态栏与下方图表的实际布局，内容区设为安全视口坐标X=0..480、Y=80..312，即整屏Y=160..392，高232。回中中心改为视口(240,196)，即整屏(240,276)。顶部状态的最后基线为视口65，下方图表说明基线为329，内容区两端留出间距。

`Projection`支持独立内容区上下界，以该区域中点作为渲染原点。横向焦距仍由480像素宽与FOV决定，避免直接缩小整个投影导致横向比例变化。中心越界检查和浮窗裁剪使用同一内容区；超50%的阈值变为X=240像素、Y=116像素。慢跟随、立即回中和重力水平不改动数学策略。

文本明确为7行，每行长度避免自动折行。边框高度从实际`StaticLayout`高度加22像素留白计算，边框与文字共同居中；文字起点相对边框，不使用原先固定Y。绘制裁剪先在屏幕坐标设置，再应用浮窗单应矩阵，防止参数栏被覆盖。

先在旧版验证两项回归失败：边框中心仍为240而非196；±8°俯仰仍未按更窄内容区立即回中。修正后覆盖7行完整排版、边框居中/容纳、±8°同帧回中、±6°移动时参数区无浮窗像素，以及内容区边界/FOV横向比例/横滚保持。编译与Lint通过后检查480×640截图并交付手机Download APK。
