# v0.3.1 浮窗重力水平修正

用户反馈稳定浮窗左侧略低，要求调到水平。按浮窗横滚倾斜处理，保留既有中心位置和跟随速度。

旧代码直接用第一帧绝对姿态作为完整参考，清除了启动时的横滚和俯仰。随后慢锚点虽然不含横滚，但保持的是这个可能倾斜的启动参考，因此启动歪头会持续影响浮窗的世界水平。

Android的两种旋转矢量和JNI Fusion ENU均使用世界+Z向上。新增固定的`LevelReference`：将世界向上方向转到启动时的视图坐标，再求其到视图+Y的最短旋转，建立重力对齐参考。后续姿态直接转入该固定参考，保留快速补偿，不逐帧重建或低通水平。兼容旧Demo基变换，覆盖反向和垂直朝向的退化情形。

每个新参考epoch的第一帧调用只吸收yaw/pitch的回中，保持原有中心体验。慢锚点、手动回中和开关维稳继续保留横滚补偿。续航流程和媒体负载不改动。

同轮用户补充：首页眼镜输入为单击切换选项、双击选中进入、长按退出。首页长按键和固件长按广播均调用Activity退出，不启动任何测试；更新页面提示。3DoF页仍长按回中。先在旧逻辑上验证两种首页长按入口无法退出，再修正并回归单击切换/双击进入测试。

验收先用仪器测试注入启动歪头2°的融合姿态，在旧代码上验证浮窗世界右向量含非零垂直分量，修正后应为零。单元测试覆盖正负小倾斜、组合运动中的世界水平、启动回中位置、任意世界航向、旧轴映射和垂直/倒置姿态。构建、Lint、相关界面/原始Fusion/后台恢复仪器测试及APK签名检查后交付。

水平依赖融合姿态的重力估计及固件遵循Android传感器约定。未标定显示光学与IMU的装配偏角，模拟器通过不能代替目标眼镜光学验收。
