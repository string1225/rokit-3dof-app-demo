## 复现与人工检查

构建使用 Android Studio JBR、既有 SDK/NDK 和 Gradle 缓存；在线 Maven 镜像首次返回 502，改用缓存离线构建通过：

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
$env:GRADLE_USER_HOME='C:\Users\junte\.gradle'
$env:ANDROID_USER_HOME='C:\Users\junte\.android'
./gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest --offline --console=plain
```

设置 `ANDROID_USER_HOME` 以复用原调试签名，避免 Windows 服务账号生成不同签名而无法覆盖安装。
